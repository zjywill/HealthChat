Vana 动作库 · 待评审清单

issue #7 的 T1/T2 产物:45 个动作,每条都有中文步骤、要领和禁忌。 这一页只用来评审,不是 app 里的界面,app 里不会有它的入口。

三条硬约束(每条都照着写的)
  • 不给次数、组数、保持秒数——强度按感觉走,同「剂量一律不给建议」那条线。
  • 没有图的动作不进库,它对模型是零增益。
  • 每条都要有「什么情况别做」,写在卡片最后一行。
  • 步骤写给没练过的人看,不用「骨盆后倾」这种词。
图片来源与授权(已查清,没有阻塞项)
  • everkinetic/data(28 张,14 个动作 × 两态)— CC BY-SA 4.0。署名 + 同样授权, 「关于」页列出处和作者即可。两态就是卡片上交叉淡入的那两帧。
  • dDara「Yoga poses」@ Flaticon(31 张)— 经 alexcumplido/yoga-api 找到的同一套图 (那个包 48 个图标,yoga-api 48 个体式,对得上)。我们自己去 Flaticon 持证下载, 不走 yoga-api 的转授:免费档署名作者,订阅档免署名。唯一限制是不能拿它做 AI 生成。
  • Gym visual(exercises-dataset 里的 GIF)、RepDB 一张都没用:前者要单独买且只有 180×180, 后者禁止随仓库再分发,拉伸也全是要弹力带的。
  • asanakit 火柴人渲染试过了,砍掉:折叠类姿势糊成一团、正反分不出来。见 issue #7 的评论。
还差什么
  • 库里只放有图的动作——一条只有文字的卡片,正是模型不用这个库也能写出来的东西。 「扶墙小腿伸展」因此没有收进来。
  • 两套图风格不一致(彩色人物 vs 单色解剖线稿),最终要统一成一套。
  • 覆盖缺口:颈肩只有 5 条、平衡只有 1 条;手腕前臂、坐姿椅子操、有氧心肺三类完全没有。 这一页最下面有一份出图清单,22 个动作、35 张图,照着生成就能补齐。

颈部前后活动Static Neck Flexion and Extension

颈肩办公室
部位
颈部
器械
徒手,坐着就能做
  1. 坐直,肩膀放松往下沉,不要耸着。
  2. 下巴慢慢往胸口收,后颈感觉被拉开,停一下。
  3. 再慢慢抬头看向斜上方,不要一路仰到底。
  4. 整个过程慢,来回几次,以不头晕为准。

要领幅度小一点没关系,速度慢才是重点;脖子发出响声不要刻意去追。

什么情况别做有颈椎病、手臂发麻、头晕史的先问医生,别自己练。

颈部侧屈Static Neck Side Flexion

颈肩办公室
部位
颈侧 / 斜方肌
器械
徒手,坐着就能做
  1. 坐直,右手轻轻搭在头的左侧。
  2. 头往右肩方向倒,左肩主动往下沉,别跟着抬起来。
  3. 手只是搭着,不要用力往下压。
  4. 换另一边。

要领拉的是肩到耳朵那条线,不是脖子后面;沉肩比压头有用得多。

什么情况别做手上不要发力下压;出现放射性的麻或刺痛立刻停。

鹰式手臂（肩背打开）Eagle

颈肩办公室
部位
肩后侧 / 上背
器械
徒手,站着坐着都行
  1. 两条手臂在身前交叉,右臂在下、左臂在上。
  2. 小臂立起来互相缠一下,手掌尽量贴在一起,贴不上就手背相对。
  3. 手肘轻轻往上抬,肩胛骨之间会有拉开的感觉。
  4. 换一边,让另一条手臂在下。

要领肩膀不要缩到耳朵边上;下半身可以不做缠腿那部分,上半身就够了。

什么情况别做肩关节做过手术或习惯性脱位的不要做。

毛巾辅助三头肌伸展Standing Triceps Extension with Towel

颈肩办公室
部位
上臂后侧 / 肩
器械
一条毛巾
  1. 右手抓毛巾一端,从头顶后面垂下来。
  2. 左手在腰后抓住毛巾另一端。
  3. 下面那只手轻轻往下带,上面那条手臂后侧会有拉伸感。
  4. 换边再做一次。

要领肋骨不要往前顶,腰不要跟着塌下去。

什么情况别做肩膀抬到一半就疼的,不要靠毛巾硬拽过去。

猫式（拱背）Cat

腰背睡前办公室
部位
脊柱 / 腰背
器械
需要跪地,垫子或地毯上做
  1. 四点跪好,手在肩膀正下方,膝盖在髋正下方。
  2. 呼气,背往上拱起来,下巴微收,肚子往里收。
  3. 回到背部平直的位置。
  4. 和下面那个牛式连起来做,一呼一吸各一次。

要领动的是整条脊柱,不是只有腰;跟着呼吸走就不会太快。

什么情况别做手腕疼的可以改成握拳撑地;膝盖不适的垫厚一点。

牛式（沉腰）Cow

腰背睡前办公室
部位
脊柱 / 腰背
器械
需要跪地,垫子或地毯上做
  1. 还是四点跪姿,手在肩下、膝在髋下。
  2. 吸气,胸口往前送,尾骨轻轻往上翘,背自然下沉。
  3. 视线看向前方偏下,不要用力仰头。
  4. 和猫式交替进行。

要领腰塌下去到舒服就停,不比谁塌得深。

什么情况别做腰椎有滑脱、椎间盘问题的把幅度收小,或者只做猫式那一半。

婴儿式Child's Pose

腰背睡前跑后
部位
腰背 / 髋
器械
需要跪地,垫子或地毯上做
  1. 跪坐下来,两个大脚趾靠在一起,膝盖分开一些。
  2. 上半身往前趴,额头找地面。
  3. 手臂往前伸直,或者放在身体两侧手心朝上。
  4. 在这里正常呼吸,感觉后背一点点松开。

要领这是个休息姿势,不用使劲;坐不到脚跟上就在屁股下面垫个抱枕。

什么情况别做孕期、膝盖弯到底就疼的不要做。

斯芬克斯式（小幅后展）Sphinx

腰背办公室
部位
腰背 / 胸前
器械
需要趴下
  1. 趴在地上,两条小臂贴地,手肘在肩膀正下方。
  2. 肩膀往下往后沉,胸口往前打开。
  3. 腿和屁股放松,不要夹紧。
  4. 感觉腰前侧被轻轻打开就停在那儿呼吸。

要领久坐一天之后这个比大幅度后弯安全得多。

什么情况别做腰一后仰就疼、或者有腰椎间盘突出的不要做。

超人式（背部激活）Supermans

腰背力量
部位
下背 / 臀
器械
需要趴下
  1. 趴好,手臂往前伸直,额头轻轻贴地。
  2. 同时抬起手臂、胸口和双腿,幅度不用大。
  3. 在最高处停一下,脖子保持自然,不要抬头看前面。
  4. 慢慢放回去,做到腰有酸胀感就休息。

要领抬起来的高度不重要,后背有在用力才重要。

什么情况别做腰部有急性疼痛时不要做。

坐姿脊柱扭转Half Lord of the Fishes

腰背办公室
部位
脊柱 / 臀外侧
器械
徒手,坐着做
  1. 坐好,右腿弯曲跨到左腿外侧,脚掌踩实。

  3. 吸气把脊柱拉长,呼气再慢慢转向右边。

鸽子式（臀外侧）Pigeon

髋腿跑后睡前
部位
臀外侧 / 髋
器械
需要跪地

蝴蝶式（内收肌）Butterfly

髋腿睡前
部位
大腿内侧 / 髋
器械
徒手,坐着做
  1. 坐好,两脚掌相对,脚跟往身体方向收一点。

  3. 膝盖自然往两边打开,不要用手往下压。

什么情况别做髋关节置换过的、腹股沟拉伤没好的不要做。

髋腿跑后
部位
大腿后侧 / 下背
器械
徒手,坐着做

站姿前屈Standing Forward Bend

髋腿跑后睡前
部位
大腿后侧 / 下背
器械
徒手,站着做
  1. 站直,双脚与髋同宽。
  2. 膝盖微微弯着,从髋部往前折下去。
  3. 让上半身和头自然垂着,手随意抓小腿或者垂下去。
  4. 起来的时候慢一点,一节一节把背立回来。

要领起身太快会头晕,这一条比拉伸本身更要紧。

什么情况别做血压偏高、有青光眼、容易体位性头晕的不要做低头位。

徒手,站着做

部位

两条硬约束
  • 不要拿 dDara 那套图当参考图或垫图。Flaticon 条款明确禁止把它们的素材用于生成式 AI （风格迁移、图生图、微调都算）。要接近那个观感只能凭文字描述独立生成。
  • 生成完先当草稿看一眼姿势对不对。画错关节角度的图比没有图更糟——用户会照着做。
出图规格
  • style：扁平彩色矢量插画，单人，线条干净，无背景装饰、无文字、无器械品牌
  • palette：肤色 + 一两件素色衣服；避免高饱和；深浅色模式下都要看得清
  • canvas：正方形，人物占画面约 80%，四周留一点空
  • fmt：优先 SVG（跟着字号缩放不糊）；PNG 的话至少 1024×1024，透明或纯白底
  • naming：gen-<id>-a.svg / gen-<id>-b.svg（只要一张时就只有 -a）
  • orientation：视角按每条标的来。正反一定要分得出来——这正是火柴人那条路被砍掉的直接原因
