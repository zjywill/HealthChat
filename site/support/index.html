Vana 支持

有问题直接写信：zjywill@gmail.com 　·　中文或英文都可以

装上之后第一件事：去「设置 › 云端模型」填一把 API key。

Vana 没有服务器，回答问题要靠你自己选的那家模型服务。没填 key 的话，它读得到你的健康 数据、首屏那段状况也照常显示，但问不出任何问题。

开始使用

为什么要我自己填 API key？

因为 Vana 不代收费用，也不架服务器。你直接和你选的那家模型服务发生关系，账单是你和它之间的事， 中间没有我们。代价是多一步配置；换来的是我们看不到你的任何数据——它不经过我们手上的任何一台机器。

怎么填

  1. 去你选的服务商那里注册并生成一把 API key（Anthropic、OpenAI、DeepSeek 等都支持）
  2. 打开 Vana ›「设置」›「云端模型」
  3. 把 key 粘进「API key」，再选 Provider 和模型

key 只保存在本机钥匙串，不进对话记录、不进备份、也不会发给除该服务商以外的任何一方。

选哪个模型？

模型下面那几颗小徽章会说清楚它能不能看图、能不能思考。 标着「不支持工具」的模型在 Vana 里基本用不了——健康数据全靠工具去读。目录里查不到的模型 （自己手填的 ID）不标徽章，那是因为猜一个能力标出去比不标更糟。

健康数据

它说读不到我的数据

去「健康」App ›「共享」›「App」› Vana，逐项看看开没开。新增的数据类型（血压、血氧、 呼吸频率、体温）需要重新授权一次才能读——已经做过选择的项 iOS 不会再问。

为什么家庭成员那边看不到健康数据？

不是权限不够，是那不是他的数据。iOS 的「健康」App 有家人共享，但苹果没有 把它开放给第三方 App——Vana 读到的永远是这台设备主人的健康库。所以切到家人时，健康相关的 功能整个不出现，而不是给你一份别人的数字。

家人那边能用的是另外三样：拍化验单识别、用药与补剂表、以及聊过的内容。

Vana 会改我的健康记录吗？

不会。对 HealthKit 只读，一次都不写。

照片与文件

拍了化验单，原图会发出去吗？

默认不会。文字识别在本机完成，发出去的只有识别出来的文字——一张化验单上有姓名、就诊号、 医院和签名，而回答问题只需要那几行数值。

只有本机一个字都认不出来的照片（一顿饭、一处皮疹这类，它们的信息本来就不是字），Vana 才会 问你一句，你点了才发。这个默认可以在「设置 › 照片」里改成一张都不问、或者每张都发； 无论哪一档，发送之前点开任意一张都能单独决定这一张发不发。

识别出来的数字不对

发送之前每一张都点得开、也改得动，改完发出去的就是你改的那一份。 气泡里也点得开。关键数值建议核对一遍再问——识别会错行错字，这一点在 app 里也写着。

支持哪些文件？

照片、PDF、docx、txt、rtf。PDF 走识别（体检报告导出来的多半是扫描件）， docx / txt / rtf 直接取文字。老的 .doc 不支持。

按住说话

识别用 iOS 的本机模型完成，录音不联网、不写入磁盘。松开只把文字填进输入框， 不会直接发送。

如果那颗麦克风按钮不出现，说明这台设备的本机语音识别不支持中文——「设置 › 语音输入」 那一段会列出它到底认得哪几种语言。本机模型是按需下载的，第一次用可能要等它准备好。

换手机

这些数据不会跟着走，需要在新设备上重新开始。对话记录、长期记忆、用药与补剂表、 以及你拍的化验单照片被明确排除在 iCloud 备份和电脑备份之外——健康数据不应该离开这台设备， 备份也不例外。

这是有意的取舍，不是 bug。要保留某一份内容的话，可以在换机之前自己截图或复制出来。

删除数据

  • 单条对话：在会话列表里左滑删除，附带的照片会一起删
  • 全部对话：「设置 › 清空对话」
  • 长期记忆：「设置 › Vana 记住的事」，可以逐条删，也可以整个关掉记忆
  • 用药与补剂：在那一页里逐条删
  • 全部：删除 App。所有数据都在 App 沙盒里，卸载即清空，我们手上没有任何副本

它不做什么

Vana 不做诊断，不能替代医生、药师或任何专业医疗建议。它给的是对你自己那些 数值的解读和一般性的说明。遇到急症相关的描述，它会先请你就医。
